# 0.14.2を使い始める

1. 外側の配布ZIPを展開してください。
2. 中の autorepair-ai-hosting-beta-0.14.2.zip をWordPressの「プラグイン → 新規追加 → アップロード」で入れます。既存Hosting Betaは置き換えます。AutoRepair AI本体は不要です。
3. 「バックアップ・復元」メニューを開きます。
4. 公開領域外の保管ディレクトリを設定します。詳細は VAULT-GUIDE-JA.md。
5. 複製環境で対象プラグインを保存し、復元を確認します。
6. 確認後、必要に応じて更新前保護を有効化します（初期状態は停止）。

サイト全体バックアップ・復元はサーバーのWP-CLIから実行します。本試作はMySQL 8.x/InnoDB・通常配置の単一サイトに限定され、実MySQLを使った通し復元は未検証です。本番への導入検証を済ませた製品という意味ではありません。

同梱central-serviceは従来の利用数管理試作です。バックアップの保存先ではありません。Stripeはテスト用下書き作成のままで、本番の自動請求を開始しません。

復元テストは RESTORE-TEST-JA.md の初回準備後、保存IDを指定して verify を実行してください。保存直後に検証する場合は backup に --verify を付けます。初回のDocker/Python設定が必要で、プラグインを入れるだけで検証が始まるわけではありません。
